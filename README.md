# Media Heroes — Guardians of the Digital World

A bilingual (Hong Kong Traditional Chinese / English) interactive cyberbullying-prevention story for classroom presentations.

## Run locally

1. Download or clone this repository.
2. Keep `index.html`, `app.js`, `styles.css` and the `assets/` folder together.
3. Open `index.html` in a modern browser. No build step or package installation is required.

## Language switching

Use the language button in the top bar on any page to switch between Traditional Chinese and English. The selected language is saved in the current browser. Switching language does not restart the story, clear choices, or add a new step to browser history.

## Story content

The story follows Amy, a school social worker and a bystander through branching cyberbullying-prevention scenarios. It is a learning scenario for prevention, empathy and online-safety discussion; it is not a direct case-management protocol and does not replace school procedures or professional judgement.
